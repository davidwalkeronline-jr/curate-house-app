How to bounce stems for the best result
  • Export every track (or each bus, like Drums or BGVs) as its own file, all starting at the very beginning of the song so they line up.
  • Turn off processing on your master bus. Keep peaks below 0 dBFS. 24 bit at 44.1 or 48 kHz is ideal.
  • Name files clearly: Kick, Snare Top, OH L, Bass DI, Lead Vox, BGV 1, AG, Keys, Pad, Click. The Studio reads the names to work out each part.
  • Include the click or guide track if you have one. It is detected and kept out of the mix, and it helps find the tempo.
